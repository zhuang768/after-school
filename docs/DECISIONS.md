# 決策

## 資料不離開裝置

沒有後端、沒有 OAuth、沒有分析。正式版 CSP 是 `connect-src 'none'`。官方說明連結由使用者自己打開，而且主機必須出現在該服務已記錄的來源裡。

OAuth 讀信可以少一次匯出檔，但需要把信箱授權交給第三方流程，審查與洩漏面都更大，也直接違背這次的隱私承諾。所以不做。

## 安裝不改 git 設定

`package.json` 的 `prepare` 只印出說明。不執行 `git config core.hooksPath`。鉤子檔在 `.githooks`，由使用者自己決定要不要啟用。

## 型別檢查

`tsc -b` 需要 composite 專案設定，這個倉庫沒有。檢查改為 `tsc --noEmit`。

## 加密

P1。PBKDF2-SHA-256、210,000 次，再以 AES-GCM 加密整個工作區。密碼只放在記憶體。忘記密碼不能重設，只能清除。這是取捨：不做後門，也不把金鑰寫進磁碟。

## 大型信箱

剖析在 Worker 裡以串流讀取，不把整個檔案收成一個字串。Node 直接呼叫與 production Worker 的 300MiB、2GiB 與 ZIP 量測都寫在 `TEST_REPORT.md`。本輪之後的重跑數字以該報告最新一節為準，不沿用「瀏覽器沒有重做」這句舊說明。

## P2 取捨

做了兩項，成本都是介面上的一小段文字：

- Today 列出曾出現密碼重設信的服務，提醒檢查救援信箱。這不是關係圖，沒有畫出「誰的救援信箱是誰」。
- 提供可複製的學校資訊單位英文短訊，讓學生自己寄出。App 不代發。

沒有做的候選：

- 瀏覽器擴充功能要常駐讀頁面，和「只在使用者匯入時處理信箱」的範圍不合。
- 密碼管理器匯出檔即使當場丟掉密碼欄，仍容易誤存機密。這次不做。

通用清單下載是 P1 的 Share the checklist，不含個人帳號名稱。

## 已核准保留不含個資的清除標記（2026-10-20）

使用者於本聊天明確核准：「可以保留不含個資的技術標記」。範圍只含 `after-school-control/kv/epoch` 隨機清除世代，不授權保留信件、帳號結果、姓名、筆記或憑證。

`Delete all my data` 刪除使用者內容、本機 storage、Cache 和這個網站的 service worker。保留標記讓其他分頁辨識過時副本，避免把已刪內容寫回。第 6 輪已實測內容清除與已知跨頁讀回回歸，UI／PRIVACY.md 也已揭露標記。本次僅記錄核准，不修改功能；仍不能描述成每個資料庫都不存在。

歷史驗收中「尚待決定」保留為當時狀態，並非當時已獲核准。此例外也不能替代安裝 PWA 後的離線實測。

## 目錄裡的 Unverified

沒有為了讓欄位看起來完整而補上記憶中的步驟。Google 的說明頁若沒有寫出 `.mbox` 這個詞，目錄就不宣稱 Google 官方把匯出格式命名為 mbox。App 能讀 mbox，是因為剖析器支援這個格式。
